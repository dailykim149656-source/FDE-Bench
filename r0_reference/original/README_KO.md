# FDE-Bench v0.2 개정 패키지

## 포함 파일

- `FDE_Bench_v0.2_Research_Protocol_KO.md`: 검토 의견을 반영한 전체 연구 프로토콜.
- `estimator_reference.py`: 표준 라이브러리만 사용하는 합성 추정기 단위검사 20개.
- `results.json`: 실행 결과, 소스 해시, 테스트 로그, 계산 예시.
- `MANIFEST.json`: 패키지 파일의 해시와 검증 범위.

## 실행

Python 3.10 이상에서:

```bash
python estimator_reference.py --seeds 1000 --out results.json
```

실패한 검사 또는 잘못된 인수가 있으면 비영(0이 아닌) 종료 코드를 반환한다. 외부 API 키, 네트워크, 추가 패키지는 필요 없다. API 모델/직접 인간 실험은 수행하지 않았다.

## 무엇을 확인했는가

A/A의 0 효과, 외생 호황의 오귀속 방지, 알려진 양·음 효과, 인계 후 차이, 대시보드 값과 실제 원장 분리, 가격과 능력 점수 분리, 탐지 민감도 가정에 따른 위험 상한을 작은 수학적 사례에서 검사한다.

## 무엇을 확인하지 않았는가

이 코드는 실제 FDE 환경이 아니다. 처리량 변화는 고정 정책에 미리 주어지며, AI가 코드를 작성하거나 조직을 설득하여 생긴 결과가 아니다. 실제 서비스 배포, 고객 조직 모델, 인간 기준선, 일반화, 안전 탐지기의 현실 민감도, 내용·외부 타당도는 미구현/미검증이다.

1,000개 seed는 1,000개 독립 사례군이 아니다. 테스트 로그의 실행 시간은 기기별로 달라질 수 있다. 동일 설정에서 비교할 재현 대상은 검사 상태와 정규화된 궤적·계산 예시이며 벽시계 시간이나 플랫폼 문자열은 아니다.

긍정 대조는 합성 원장의 알려진 한 위반 신호에 대한 검사다. 실무 사고 탐지율이나 전체 사고율 상한을 보증하지 않는다. `results.json`의 위험 상한 값들은 가정하에 계산한 설명 예시다.

## 원본 보존

v0.1은 수정하지 않았다. 원본 해시는 개정 프로토콜에 기록되어 있다. 결과 생성 이후 소스가 바뀌면 다시 실행하여 `results.json`의 `source_sha256`을 갱신한다.
